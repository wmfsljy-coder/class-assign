# 신입생 반편성 도우미

중학교 내신 성적(학년석차 백분율 등)이 들어 있는 엑셀 명단을 올리고 조건을 고르면, 반을 자동으로 나눠 주는 웹앱입니다. 어느 학교든 무료로 쓸 수 있습니다.

- 성적은 반마다 고르게 (성적 구간마다 같은 수, 반 평균·표준편차까지 맞춤)
- 동명이인·형제자매(보호자 연락처가 같은 학생)는 다른 반으로
- 남녀 성비, 출신 중학교별 인원을 반마다 고르게
- 같은 반이 되면 안 되는 학생, 반을 정해 둘 학생 직접 입력
- 정원 외 학생(특수교육대상자 등)은 성적 없이 나눠 배치하거나 한 반에 모아 배치
- 반별 인원을 직접 정하기 (예: 특수교육대상자 포함 반 감축)
- 결과 화면에서 학생 반을 직접 바꾸면 통계가 바로 다시 계산
- (v1.1) 출신 중학교별 성적 보정값 계산: 지난 입학생의 출신학교·중학교 성적·고1 성적 엑셀을 올리면, 같은 내신이면 고교에서 더 잘하는(못하는) 학교를 찾아 보정값을 만들어 줌
- 엑셀 내려받기: 전체 결과, 반편성표(반별 나란히), 반별 통계(수식 포함), 나누기 확인, 원본+배정반, 반별 명단

## 개인정보

올린 파일은 브라우저 안에서만 처리됩니다. 페이지의 보안 정책(`connect-src 'none'`)으로 외부 전송이 막혀 있고, 어디에도 저장하지 않습니다.
인터넷이 막힌 업무용 PC에서는 `offline/class-assign-offline.html` 파일 하나만 받아 더블클릭해서 쓰면 됩니다.

## 쓰는 법

1. 명단 엑셀 올리기 (첫 줄 근처에 성명·성별·출신학교·성적 제목이 있으면 열을 자동으로 찾음). 화면의 「빈 양식 내려받기」, 「예시 자료로 연습해 보기」를 쓸 수 있습니다.
2. 학급 수와 조건 고르기 → 반편성 실행
3. 결과 확인·수정 → 엑셀로 내려받기

## 파일

- `index.html`, `app.css`, `app.js`: 화면
- `calib.js`: 출신 중학교별 보정값 계산 (해마다 등수 백분율로 바꾼 뒤, 중학교 등수로 고1 등수를 예측한 직선에서 학교별 평균 차이를 구하고, 학생 수가 적을수록 0 쪽으로 줄임)
- `engine.js`: 배정 계산 (성적 구간 지그재그 배치 후 담금질 방식으로 교환하며 조건 최적화)
- `vendor/xlsx.bundle.js`: 엑셀 읽기·쓰기 ([xlsx-js-style](https://github.com/gitbrent/xlsx-js-style), Apache-2.0)
- `build-offline.mjs`: 오프라인용 단일 파일 만들기 (`node build-offline.mjs`)
